# 23-Bit Single Cycle MIPS CPU 

The objective of this project was to designn a 23-bit MIPS CPU based on ISA with particular operations following R-type, I-type, J-type format.

# Assembly Instructions Reference

This repository contains a reference for common assembly instructions used in various architectures. Below is a table explaining each instruction and its function.

| Instruction | Description                         |
|------------|-------------------------------------|
| `SLT`      | Shift Less Than                    |
| `SLL`      | Shift Left Logical                 |
| `SUB`      | Subtract                           |
| `JMP`      | Jump                               |
| `AND`      | And operation                      |
| `LW`       | Load                               |
| `ADDi`     | Add Immediate                      |
| `NOP`      | No Operation                       |
| `NOR`      | Nor operation                      |
| `BEQ`      | Branch on Equal                    |
| `OR`       | Or operation                       |
| `ADD`      | Add                                |
| `BNE`      | Branch on Not Equal                |
| `SRL`      | Shift Right Logical                |
| `SW`       | Store                              |

## Usage

This repository serves as a quick reference for understanding and implementing assembly instructions in low-level programming.
